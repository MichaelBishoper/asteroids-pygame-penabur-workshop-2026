# Instructions For Mentors
## Cloning the Repository
```git
cd path/to/your/projects

git clone https://github.com/MichaelBishoper/asteroids-pygame-penabur-workshop-2026

cd asteroids-pygame-penabur-workshop-2026
```
## Running the Game
From the project root:
```
python main.py
```
**Note**: Use `python3` for linux and check your python PATH variable for windows as it may use a different alias.
